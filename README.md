# POS

Requirements:
-create a laravel project 8 with tailwind css
-create a login page with dummy admin@mail.com password 12345678
-after login for admin redirect to admin dashboard

    -Product Management
    - Reports such as
       - transaction list ( Orders, Receieved product, and etc)
       - expense list
       - collection list

 -we have a navbar consist of:
    -icon to minimize the dashboard to show only the icon
